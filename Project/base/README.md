# Base model

The building everyone works on. **TBC — add before Week 04.**

Expected contents:

- `base-building.3dm` — massing, floor levels, core, structural grid. Ordinary
  on purpose: the design work is the skin, not the volume.
- `site.3dm` — context massing and ground, as reference geometry
- `sun/` — sun path data for the site, or the location string to generate it

## Rules

- **Do not edit these files.** Reference them (`_Insert` as reference, or
  worksession) so an update reaches everyone.
- Model in metres, tolerance 0.001 — same as
  [`Reference/cdf-template.3dm`](/Reference/cdf-template.3dm).
- Your work goes in your own submission folder, never here.
