# Setup

One tool. That is the whole toolchain.

## Rhino 8

[rhino3d.com/download](https://www.rhino3d.com/download) — 90-day evaluation, and
NCKU runs a class licence server (details in the first session). An educational
licence is roughly a tenth of commercial and is worth owning.

- **macOS and Windows are both fine.** Everything in this course works on either.
- **Grasshopper is included.** There is nothing extra to install and no separate
  download — it is the `Grasshopper` command inside Rhino.
- Rhino 7 will open most of this course, but several things assume 8. Use 8.

That is it — one application. No separate downloads, no package manager, no
terminal, no git.

> Rhino has a command line **of its own**, and you will live in it — that is
> Week 01. What you do not need is a *system* shell.

## Get the course files

Download this repository as a ZIP (green **Code** button ▸ *Download ZIP*), or
clone it if you already know how. Either is fine — nothing here depends on
version control.

Re-download when material is added; the schedule in the
[README](README.md) says when that happens.

## Start from the template

[`Reference/cdf-template.3dm`](Reference/cdf-template.3dm) has units,
tolerance and the layer structure already set. Open it, `SaveAs` under your own
name, and model in that.

Starting from it means the two settings that are painful to change later are
already right — see [Week 01](Lecture/Week_01/README.md).

## Handing work in

`TBC-SUBMISSION` — Moodle folder, shared drive, or whatever the course uses.
File naming is in each week's page.

## Checking your own work

[SELF-CHECK.md](SELF-CHECK.md) — eight Rhino commands, about two minutes. Run it
before every hand-in and before asking why something is broken.
