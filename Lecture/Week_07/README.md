# Week 07 — A twisting tower

🔹 **Standalone build**

Lists, series and transformations on a form that is not the facade, ending on a problem we cannot solve yet.

## What this session covers

- a floor plate repeated by `Series`: heights as a list
- rotation and scale *per floor*: two lists that must line up
- lofting through a list of curves
- the moment one list becomes many: points on every floor

## In the room

**Today's goal:** A 30-storey tower whose square floor plates rotate and taper upward, with a skin and, if we can, vertical mullions.

We build it together, live, from the data flow in [`goals.md`](/Lecture/Week_07/goals.md). At **3 critical points** I stop and you vote on what we place next (🗳️ in `goals.md`, polls run on `TBC-POLL-TOOL`), then we argue about the result before anyone touches the canvas. See [how the builds work](/README.md#how-the-builds-work).

You will not be given a `.gh` file. [Reading one teaches nothing, and the building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).

## Homework

- Finish the tower up to the cliffhanger; vary twist and taper and keep three screenshots
- Write down in one sentence what you think the mullion problem is. We will check it next week.
