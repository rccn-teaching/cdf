# Week 07 — Data trees I: what a path actually is

The concept people bounce off. Two weeks, because one is a lie you notice in Week 11.

## What this session covers

- what `{0;1;2}` means, read out loud
- how a component's inputs decide the output's structure
- matching: shortest, longest, cross reference
- reading the tree in the Param Viewer *before* reaching for a fix

## In the room

**Three goals**, each stated as a data flow — see [`goals.md`](/Lecture/Week_07/goals.md).
Built together, then in pairs, then alone. Goal 3 is the one that does the
work; see [the format](/README.md#three-goals).

You will not be given a `.gh` file. [Reading one teaches nothing, and the
building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).

## Homework

- Build all three goals
- Attach a Param Viewer in three places in your own definition
