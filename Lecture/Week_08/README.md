# Week 08 — Data trees II: graft, flatten, and the honest fix

When flatten is right, and when it is you giving up.

## What this session covers

- `Graft`, `Flatten`, `Simplify`, `Trim Tree` — what each does to paths
- the flatten reflex, and the bugs it hides rather than fixes
- `Path Mapper`: powerful, unreadable, and a sign something upstream is wrong
- diagnosing a wrong result as a tree problem rather than a geometry one
