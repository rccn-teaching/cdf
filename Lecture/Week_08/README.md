# Week 08 — Data trees: one week, on real problems

🌳 **Concept week** · the single data-structures week

The tower's mullions and the facade's louvres both stopped on the same thing. Today we learn to read it.

## What this session covers

- `{0;1;2}` is a sentence: read it out loud
- how a component's inputs decide its output's structure
- Graft, Flatten, Simplify, Flip Matrix: what each does to the paths
- matching: shortest list, longest list, cross reference
- the flatten reflex hides bugs; Path Mapper is a last resort

## In the room

**Today's goal:** Fix the two problems we left open: the tower's 12 mullions (W07), and louvres per bay on the facade (W06). Diagnose before touching anything.

We build it together, live, from the data flow in [`goals.md`](/Lecture/Week_08/goals.md). At **4 critical points** I stop and you vote on what we place next (🗳️ in `goals.md`, polls run on `TBC-POLL-TOOL`), then we argue about the result before anyone touches the canvas. See [how the builds work](/README.md#how-the-builds-work).

You will not be given a `.gh` file. [Reading one teaches nothing, and the building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).

## Homework

- Fix your own definition with a Param Viewer in three places, and annotate each with a Scribble saying what the paths mean
- 🎓 **Concept review**: one sketch, one paragraph, one reference
