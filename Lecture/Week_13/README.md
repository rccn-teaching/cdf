# Week 13 — Form-finding

Letting a constraint decide the shape.

## What this session covers

- relaxation as a design method, not an effect
- anchors, springs, and reading a solver that will not settle
- form-found geometry as a starting point rather than an answer
- **Mac note:** Kangaroo runs in Rhino 8 on both platforms

## In the room

**Three goals**, each stated as a data flow — see [`goals.md`](/Lecture/Week_13/goals.md).
Built together, then in pairs, then alone. Goal 3 is the one that does the
work; see [the format](/README.md#three-goals).

You will not be given a `.gh` file. [Reading one teaches nothing, and the
building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).

## Homework

- Build all three goals
- If it suits your strip, take it into the project. If not, say why not

## Commands

The commands this week centres on. If one of these is not covered by the prose above, that's a signal to teach it — the list here is the week's source of truth for what students walk in expecting to use.

```
Kangaroo: Solver
Anchor
Length (Line)
Load
EdgeLengths
Naked Vertices
Show
Grab
```
