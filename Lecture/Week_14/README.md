# Week 14 — Fabrication prep: unroll, nest, label

The week the model has to be true.

## What this session covers

- unrolling from Grasshopper; developable vs not, and the honest workarounds
- nesting, sheet efficiency, and material constraints as inputs
- labelling and the panel schedule — identity surviving to the cut file
- tolerance and kerf: the gap between the model and the machine

## In the room

**Three goals**, each stated as a data flow — see [`goals.md`](/Lecture/Week_14/goals.md).
Built together, then in pairs, then alone. Goal 3 is the one that does the
work; see [the format](/README.md#three-goals).

You will not be given a `.gh` file. [Reading one teaches nothing, and the
building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).
