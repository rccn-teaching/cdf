# Week 12 — Meshes, and when not to use NURBS

Two geometries, two jobs. Conversion as a decision.

## What this session covers

- mesh vs NURBS: what each is good at and what each costs
- mesh topology: vertices, faces, naked edges, welding
- when to convert, in which direction, and what you lose
- meshes from scans and surveys — cleaning inbound data

## In the room

**Three goals**, each stated as a data flow — see [`goals.md`](/Lecture/Week_12/goals.md).
Built together, then in pairs, then alone. Goal 3 is the one that does the
work; see [the format](/README.md#three-goals).

You will not be given a `.gh` file. [Reading one teaches nothing, and the
building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).

## Homework
