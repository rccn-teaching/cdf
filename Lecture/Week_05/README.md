# Week 05 — The canvas and the flow

Parameters, components, wires — and reading a definition as a thing with a direction.

## What this session covers

- the canvas; params vs components; what a wire actually carries
- referencing Rhino geometry, and why internalising matters from day one
- the panel as the only debugger you get
- grouping and naming as you build, because Week 15 is about the mess you make now

## In the room

**Three goals**, each stated as a data flow — see [`goals.md`](/Lecture/Week_05/goals.md).
Built together, then in pairs, then alone. Goal 3 is the one that does the
work; see [the format](/README.md#three-goals).

You will not be given a `.gh` file. [Reading one teaches nothing, and the
building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).

## Homework

- Build all three goals
- Your project variant is assigned this week
