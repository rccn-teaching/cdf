# Week 15 — Make it readable, make it fast

🧱 **Class build** · part 5 of 5

The class definition, built over five sessions, is a mess. Today we make it something a stranger could drive.

## What this session covers

- group, name, colour: lay out a definition to be read
- internalise data; make the file open elsewhere
- what is actually slow: previews, recomputation, huge trees
- the review question: could someone else drive this?

## In the room

**Today's goal:** The class definition, cleaned for a reader: inputs gathered and named, one group per step, slow parts found and fixed, and it opens on a stranger's laptop.

We build it together, live, from the data flow in [`goals.md`](/Lecture/Week_15/goals.md). At **3 critical points** I stop and you vote on what we place next (🗳️ in `goals.md`, polls run on `TBC-POLL-TOOL`), then we argue about the result before anyone touches the canvas. See [how the builds work](/README.md#how-the-builds-work).

You will not be given a `.gh` file. [Reading one teaches nothing, and the building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).

## Homework

- Clean your own definition for a reader; swap with a podmate, who changes three parameters without asking you anything
- 📚 **Library recipe**: one reusable pattern from your project, written up for the class library
- Pod review
