# Week 15 — Definition hygiene and performance

Why your file takes 40 seconds, and why a stranger cannot read it.

## What this session covers

- grouping, naming, colour, laying a definition out to be read
- internalising data and making a file that opens elsewhere
- what is actually slow: previews, redundant recomputation, huge trees
- the review question — could someone else drive this?

## In the room

**Three goals**, each stated as a data flow — see [`goals.md`](/Lecture/Week_15/goals.md).
Built together, then in pairs, then alone. Goal 3 is the one that does the
work; see [the format](/README.md#three-goals).

You will not be given a `.gh` file. [Reading one teaches nothing, and the
building is the skill](https://kb.rccn.dev/computation/rhino-grasshopper/grasshopper/describing-a-definition).
